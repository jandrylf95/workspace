#### Didactic guide

**Unit 3 Software Projects**

**Stage of a project**  
Definition: 
- Problem statement
- Initial architecture document
- Project Management plan

Start:
- Define an infrastructure
- Recruit participants
- Organize work team
- Define key milestones
- Launch the project

Execution:
- Develop the system
- Create reports
- Identify potetial problems

Finish:
- Deploy the project.

**Team roles:**
- Management
- Development
- Crossed roles
- Consultation roles

Tasks and Work Products
- A group of tasks is called `Activities`.

*EDT*
**Work Breakdown Structure (WBS)**  
- Project management tool
- split the project in small parts.
- Breakdown into hierarchical levels.  

Principal Topics:
- Define the project scope. 
      - Constitution documents
      - Key deliverables
- Key deliverables
      - Split the project
- Breakdown into packages
- Define packages
      - Must be small
- Represent in a hierarchical diagram.
      - Use tree-style diagrams or a coded structure.

**Project Phases**  
`Project Start` (Needs, General Scope, Goals, Stakeholders, Initial resources)  
`Planification` (Work plan, Schedule, Budget, Human and technological Resources, Threats and mitigation strategies, `WBS` `EDT`)  
`Project Execution` (Work on activities, development, partial tests, team communication and coordination)  
`Monitoring` (supervise, compare, correct deviations, update plans)  
`Closure` (Delivers to customer, Document learnings, customer training)
